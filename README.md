# طقس وفلك سراة عبيدة — الموقع

موقع متعدد الصفحات: الرئيسية، والنشرة الشهرية، ولوحة الأحداث، وسهيل، والهلال،
والخسوف، والطقس، والأمطار، وصفحة لكل حدث كبرى موسمي. تُستضاف على GitHub Pages،
وتُولَّد كل صفحاته آلياً من المحرّك في المستودع الخاص — لا تُحرَّر هنا يدوياً.

**المصدر الأصلي للمشروع والمحرّك:** مستودع خاص.

> **الاسم:** كان «زيج سراة عبيدة» ثم «تقويم سراة عبيدة الفلكي»، **واستقرّ على
> «طقس وفلك سراة عبيدة» في ١١ أغسطس ٢٠٢٦.** والرابط ومسار GitHub Pages لم
> يتغيّرا في شيء من ذلك — فما يزال العنوان يحمل `zij` من التسمية الأولى، ولا
> يُغيَّر لئلا ينكسر رابطٌ منشور.

- الحدود الإدارية: OpenStreetMap برخصة ODbL
- تقويم الكواكب: JPL DE440s
- مواقع النجوم: Hipparcos
