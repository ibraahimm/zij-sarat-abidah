# زيج سراة عبيدة — الموقع

موقع متعدد الصفحات: الرئيسية، ولوحة الأحداث، وسهيل، والهلال، والخسوف، وصفحة
لكل حدث كبرى موسمي. تُستضاف على GitHub Pages، وتُولَّد كل صفحاته آلياً من
المحرّك في المستودع الخاص — لا تُحرَّر هنا يدوياً.

**المصدر الأصلي للمشروع والمحرّك:** مستودع خاص.

- الحدود الإدارية: OpenStreetMap برخصة ODbL
- تقويم الكواكب: JPL DE440s
- مواقع النجوم: Hipparcos
